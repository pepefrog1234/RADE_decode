RADE Decode v1.2 — TestFlight Release Notes

What's New
This release fixes four field-reported issues: received SNR not appearing on FreeDV Reporter, HOLD TO TALK dropping out of transmit while held, spaces not working in the Status Message field, and reporter settings being hidden while reporting is off.

Fixed
1. FreeDV Reporter SNR: the SNR column on qso.freedv.org is no longer blank. The app now reports the current SNR every 10 seconds while synced (same as the desktop version), plus an immediate report when a callsign is decoded.
2. HOLD TO TALK: transmit no longer drops while the button is held. Re-pressing PTT during the ~1 s end-of-over tail (or a brief touch loss while pressing hard) could silently unkey the radio mid-hold; the radio now stays keyed and the over resumes seamlessly. A 200 ms release debounce absorbs momentary touch losses. Also fixed a race where a very fast press-release could leave the radio stuck in transmit.
3. Status Message: spaces can now be typed, and pressing Return sends the updated message immediately.
4. Settings: Callsign, Grid Square, Frequency, and Status Message can be entered while "Enable Reporting" is OFF, so everything can be prepared in advance.

What to Test

1. FreeDV Reporter SNR
- Enable reporting, start RX, achieve sync on any RADE signal
- Within ~10 s your row on qso.freedv.org shows an SNR value, refreshing during reception
- After an end-of-over callsign decode, RX Call and SNR update immediately
- Re-syncing after a sync loss produces a fresh report right away

2. HOLD TO TALK stability (IC-705 over WiFi)
- Hold PTT for 10+ seconds, the radio stays keyed the whole time
- Press, release, and immediately press again (within ~1 s), the radio must NOT unkey during the second hold
- While holding, deliberately roll/slide the fingertip, transmit continues uninterrupted
- Normal release still unkeys after the ~1.3 s tail and the remote station still decodes the EOO callsign

3. Status Message
- Type a message containing spaces (e.g. "QRV 40m JA1XXX"), spaces appear as typed
- Press Return, the message updates on qso.freedv.org immediately

4. Settings visibility
- With "Enable Reporting" OFF, all reporter fields are visible and editable
- Turn reporting ON, the pre-entered values are used as-is
- With the IC-705 audio source selected, Frequency still shows as locked (synced from the radio)

5. Regression check
- Normal RX, decode, and reception logging still work
- Background capture and foreground analysis still work
- Reporter connects only while RX is running and disconnects on STOP

Notes
- Waterfall: intentionally replaced by the Band Activity list (lower CPU; finding active frequencies is what the list does better). The spectrum display remains. This is by design.
- Microphone gain: the hardware input gain is deliberately fixed to bypass iOS AGC (Control Center changes are overridden by design). Use Settings > RX Input Gain to adjust the receive level.
- The IC-705 "No login reply" report concerns the Android app and is not part of this iOS build.
- Slow RX waveform recovery (~10 s) after transmit: the IC-705 occasionally stops its audio stream after an over; the app detects and restarts it automatically. Reports with timestamps help us tune this further.
